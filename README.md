# Splunk SIEM Log Analysis

**Target role:** SOC Analyst L1  
**Focus:** SPL • Log investigation • Suspicious-activity triage • Evidence-based reporting

This repository contains Splunk exercises covering common network and service logs. Start with one scenario and follow it from data ingestion through analysis and written findings.

## What This Can Demonstrate
- Searching and filtering events with SPL
- Extracting and comparing relevant fields
- Summarising events to identify patterns for investigation
- Turning evidence into a clear analyst conclusion

## What to Look For in Each Case
For an interview-ready case study, include the data source, ingestion settings, SPL query, query explanation, sanitized observed output, interpretation, possible benign explanations, limitations, and recommended next steps. Add screenshots only when they show your own tested results.

## Tools
Splunk Enterprise/Free, SPL, and sample DNS, FTP, HTTP, SSH, SMTP, DHCP, or Zeek logs.



## Evidence screenshots

Add genuine screenshots from your own Splunk run to the individual case studies. For the minimum useful set—event ingestion, the SPL query with results, and a relevant event detail—see the [Screenshot Guide](https://github.com/bala-soc/Splunk-Projects/blob/main/SCREENSHOT_GUIDE.md).

Screenshots should support the written findings and match the query in the document. Do not use mock screenshots or claim untested output as a verified result.
