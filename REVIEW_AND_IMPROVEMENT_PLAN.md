# Splunk Projects — Review & Improvement Plan

This file was useful during a portfolio review, but it is not required as a permanent repository deliverable. The actionable corrections below are being applied directly to the relevant project write-ups. Keep project READMEs focused on the investigation and its evidence rather than internal review commentary.

## Quality standard for this repository
- Use the correct index and sourcetype for the dataset.
- Only query fields that actually exist or are explicitly extracted.
- Clearly separate observed findings from hypotheses and expected outcomes.
- Include data source, setup, query, result evidence, limitations, false positives, and recommended next steps.
- Do not claim a threat was detected unless the sample data and analysis support that conclusion.
