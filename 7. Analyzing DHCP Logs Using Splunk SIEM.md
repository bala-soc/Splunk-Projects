# DHCP Log Analysis with Splunk

## Objective
Review DHCP assignment activity and identify events that may need network troubleshooting or additional security review.

## Dataset and Setup
- **Sample source:** [Security datasets — DHCP log](https://www.secrepo.com/maccdc2012/dhcp.log.gz)
- **Example sourcetype:** `dhcplog`
- **Index:** The searches use `main`; change it to match your Splunk setup.
- Field names vary across DHCP products and log formats. Verify the actual event structure before running analysis queries.

## 1. Ingest and Validate
Upload the sample with **Settings → Add Data → Upload**, then verify events:

```spl
index=main sourcetype=dhcplog
| head 10
```

## 2. Discover Fields
```spl
index=main sourcetype=dhcplog
| fieldsummary
```

Record the actual names for assigned address, client identifier/MAC, DHCP message type, lease details, and timestamp where present. Create and validate field extractions if needed.

## 3. Summarise Observed Assignment Events
If the extracted address field is `assigned_ip`:

```spl
index=main sourcetype=dhcplog
| stats count by assigned_ip
| sort - count
| head 20
```

Interpret counts according to the event type. Repeated events may reflect renewals or normal client activity.

## 4. Review Activity Over Time
```spl
index=main sourcetype=dhcplog
| timechart span=1h count
```

## 5. Review a Client Identifier
After identifying an actual client identifier in the logs, replace `<CLIENT_ID>` below with that observed value:

```spl
index=main sourcetype=dhcplog client_identifier="<CLIENT_ID>"
| table _time client_identifier assigned_ip
| sort 0 _time
```

Use only field names that exist in your dataset. An unfamiliar client identifier is not necessarily unauthorised; compare it with asset inventory and the authorised network scope.

## Investigation Report
Record the source and schema, query, observed result, relevant time range, possible benign explanations, limitations, and follow-up evidence required. Redact real MAC addresses, IPs, hostnames, and client identifiers before publishing.
